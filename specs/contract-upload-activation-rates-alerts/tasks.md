# 合同上传、生效、费率与预警执行计划

## 已确认范围

本计划只调整合同上传、合同生效完整性、管理费率维护、订单利润口径和合同预警展示。保留原始台账、上传记录、数据权限、订单修正、额度统计和审计链；不执行 CloudBase 迁移或部署。

## 业务规则

1. 合同台账上传

- 核心字段可解析的合同在上传后直接进入 `active`（执行中），不再保持待生效等待管理费率。
- 受控省级字典中存在的省份自动配置；可识别的一个或多个经营单位自动关联到合同。
- 多经营单位额度按合同含税金额平均分配，统一以整数分计算；无法整除的余数按稳定经营单位排序逐分分配，确保分配合计严格等于合同额。
- 未识别经营单位不阻断核心合同生效，但来源行保留待维护说明；该经营单位的订单在关联条件未满足前仍进入待维护。
- 合同日期、金额、编号或省份等核心字段不可解析时，不创建生效合同，原始行保留为待维护。

2. 管理费率

- 上传阶段不校验、不生成管理费率。
- 合同生效完整性校验移除“每个经营单位必须已有管理费率”。
- 订单缺少管理费率时仍为有效订单：计入完工金额、合同进度、额度消耗、超额计算和订单统计。
- 缺少费率的订单默认使用 `0` 基点（0%）快照，毛利润按 0 正常计算并参与汇总。
- 汇总和概览按 0% 口径展示利润；后续补录费率后重算对应业务月份利润，完工进度不受影响。

3. 合同概览中的管理费率维护

- 合同概览详情新增费率维护区域，基于现有“合同 + 经营单位 + 生效月份”费率历史模型。
- 提供单经营单位维护、全部经营单位统一设置、勾选多个经营单位批量设置、复制历史月份到新月份后局部调整四种操作。
- 相同合同、经营单位和生效月份已有费率时，显式确认更新并写入审计日志。
- 费率补录或更新后，回填对应业务月份订单的费率快照和毛利润，重算受影响月份的利润汇总；不重算完工进度。

4. 合同预警

- 用户可见合同预警不再显示 `expired`（已过期）类型。
- 到期前提醒、接近满额、满额/超额等其他预警保持现有逻辑。
- 历史 `expired` 预警记录保留在审计/数据表中，不物理删除；仅从合同详情和经营分析预警接口的用户可见结果中过滤。

## 实施步骤

- [x] 1. 合同上传直接生效与平均额度分配
  - 调整台账导入器：将可解析核心合同创建为 `active`，锁定合同金额。
  - 用稳定排序的整数分平均算法写入多个经营单位额度。
  - 保留无经营单位或无法识别范围的来源行提示，不阻断可生效合同。
  - _Requirements: 上传即生效、平均额度、原始行保留_

- [x] 2. 移除费率对合同和订单的阻断
  - 更新合同完整性校验，移除费率必填条件。
  - 更新订单导入和维护：费率缺失时订单有效，费率快照默认 0 基点，毛利润按 0 计算。
  - 调整聚合与分析：完工和利润全量汇总，默认费率订单按 0% 口径参与利润计算。
  - _Requirements: 费率只影响利润，不影响订单/进度_

- [x] 3. 合同概览费率工作台
  - 在合同概览详情中补齐经营单位费率表、统一设置、批量设置、复制月份和局部修改。
  - 复用现有费率 API；仅在缺少批量操作能力时新增受限的合同域 API。
  - 写入操作日志并触发限定月份利润重算。
  - _Requirements: 管理员高效维护差异化管理费率_

- [x] 4. 已过期预警隐藏
  - 从合同预警、经营分析预警和合同详情展示中过滤 `expired`。
  - 保留预警表和审计历史，不删除历史记录。
  - _Requirements: 不再显示已过期合同提醒_

- [x] 5. 自动化验证
  - 覆盖平均分配、余数分配、无费率订单的 0% 利润口径、费率补录回填、预警过滤和权限范围。
  - 运行 API/Web 类型检查、构建、迁移校验和相关合同/订单回归。
  - _Requirements: 本地可验证、无相邻功能回归_

- [ ] 6. 本地人工验收
  - 验收合同上传后直接生效、经营单位平均额度、无费率订单进度、合同概览批量费率维护和已过期预警隐藏。
  - 用户确认“本地测试通过，可以部署”前不执行 CloudBase 操作。
  - _Requirements: 发布门禁_

## 验收清单

- 200 万元、4 个经营单位的合同，自动生成 4 条各 50 万元额度。
- 100 元、3 个经营单位的合同，额度合计严格为 100 元，余数可追溯。
- 未维护管理费率的订单上传成功，完工与进度增长，毛利润按 0% 参与计算。
- 管理员补录费率后，相应月份利润按新费率重算，完工与进度数值不改变。
- 合同详情和经营分析不显示已过期提醒，其他预警仍显示。
- 上传记录、原始台账重建、权限与订单修正流程保持可用。
