## 1. 项目结构

```
mini-program/                  ← 整个小程序的根目录
├── app.js                     ← 全局入口（启动时第一个运行）
├── app.json                   ← 全局配置文件
├── app.wxss                   ← 全局样式表
├── sitemap.json               ← 微信搜索配置
├── project.config.json        ← 开发者工具配置（不用管）
├── project.private.config.json ← 个人私有配置（不用管）
│
├── utils/                     ← 工具函数文件夹
│   ├── constants.js           ← API 地址管理
│   ├── config.default.js      ← 默认配置模板
│   ├── config.prod.js         ← 生产环境配置
│   ├── request.js             ← 网络请求封装
│   └── auth.js                ← 登录/注册
│
└── pages/                     ← 页面文件夹（每个页面一个子文件夹）
    ├── login/                 ← 登录页
    ├── index/                 ← 首页
    ├── package-month/         ← 月度数据填报页
    ├── messages/              ← 消息中心
    ├── privacy/               ← 隐私政策
    └── terms/                 ← 服务协议
```

**每个页面文件夹里有对应的 4 个文件**（以 login 为例）：
| 文件 | 作用 | 类比 |
|------|------|------|
| `login.wxml` | 页面长什么样 | 建筑图纸 |
| `login.wxss` | 页面穿什么衣服 | 装修风格 |
| `login.js` | 页面有什么动作 | 行为逻辑 |
| `login.json` | 页面独有的配置 | 房间说明书 |

**逐句解释：**

- `sitemapLocation`：指向 sitemap.json，控制小程序内容是否被微信搜索收录。

## 3. app.js —— 小程序的发动机

```javascript
const { BASE_URL } = require('./utils/constants');  // ①

App({                                                  // ②
  globalData: {                                        // ③
    userInfo: null,     // 用户信息，初始为空
    cityId: null,       // 用户所在城市 ID，初始为空
  },

  onLaunch() {                                         // ④
    const token = wx.getStorageSync('token');          // ⑤
    if (token) {                                       // ⑥
      this.checkLogin(token);
    }
  },

  checkLogin(token) {                                  // ⑦
    // 直接发起网络请求，不经过 request.js（避免自动跳登录页）
    wx.request({
      url: `${BASE_URL}/me`,                           // ⑧
      timeout: 8000,                                   // ⑨
      header: { Authorization: `Bearer ${token}` },   // ⑩
      success: (res) => {                              // ⑪
        if (res.statusCode === 200) {                  // ⑫
          this.globalData.userInfo = res.data;         // ⑬
          this.globalData.cityId = res.data.cityId;    // ⑭
        } else {
          wx.removeStorageSync('token');               // ⑮
        }
      },
      fail: () => { /* 网络错误就算了，不做处理 */ }    // ⑯
    });
  },
});
```

### 逐句翻译

① **`const { BASE_URL } = require('./utils/constants');`**
- `require` 是 Node.js/微信小程序里加载别的 JS 文件的方法。
- 相当于从工具箱 `constants.js` 里拿出 `BASE_URL` 这个变量（后面会讲）。
- `BASE_URL` 就是 API 的基础地址，比如 `https://api.example.com/api`。

② **`App({...})`**
- `App()` 是微信小程序提供的函数，用来注册整个小程序。
- 里面写的对象就是小程序的"全局配置和行为"。
- 类比：`App()` 像开了一家公司，里面的 `globalData` 是公司公用的资源。

③ **`globalData: { userInfo: null, cityId: null }`**
- 全局数据，任何页面都可以通过 `getApp().globalData` 访问。
- `userInfo` 存用户信息（名字、角色等），`cityId` 存用户所属城市 ID。
- 初始值都是 `null`，登录成功后才被赋值。

④ **`onLaunch()`**
- 微信小程序的生命周期函数。**小程序启动时自动调用一次**。
- 类比：你开店，`onLaunch` 就是开门营业那一瞬间自动触发的事件。

⑤ **`const token = wx.getStorageSync('token');`**
- `wx.getStorageSync`：从微信本地缓存中读取数据。
- `'token'` 是键名。如果之前登录成功过，缓存里就有 token。
- `Sync` 后缀表示**同步**操作，意思是不等结果直接拿，速度快但如果没有数据会返回空。
- token 就是登录凭证——相当于你进游乐场的门票，有了它就不用重新买票。

⑥ **`if (token) { this.checkLogin(token); }`**
- 如果本地缓存里有 token（票还在），就用它向服务端验证是否仍然有效。

⑦ **`checkLogin(token)` —— 自定义方法，检查登录是否仍然有效**
- 这个名字是自己起的，不是微信规定的。
- 作用是带着 token 去问服务器"这个用户还有效吗？"

⑧ **`` `${BASE_URL}/me` ``**
- JavaScript 的模板字符串（反引号 + `${}`）。
- 实际拼出来像是 `https://api.example.com/api/me`。
- `/me` 是后端的一个接口，返回当前登录用户的信息。

⑨ **`timeout: 8000`**
- 网络请求最多等 8 秒，超时就算失败。
- 防止用户等太久。

⑩ **`header: { Authorization: \`Bearer ${token}\` }`**
- HTTP 请求头。`Authorization` 是标准的认证字段。
- `Bearer` 是"持有人"的意思，后面跟着 token。
- 服务器收到后会解析 token，确认这是哪个用户。

⑪ **`success: (res) => {...}`**
- 网络请求成功的回调函数。`res` 是服务器返回的完整响应对象。
- 箭头函数 `(res) => {...}` 是 ES6 语法，相当于 `function(res) {...}`。

⑫ **`res.statusCode === 200`**
- HTTP 状态码。200 表示请求成功。
- 其他状态码（如 401 未授权、500 服务器错误）都说明有问题。

⑬ **`this.globalData.userInfo = res.data;`**
- 把服务器返回的用户信息存入全局数据，供其他页面使用。
- `res.data` 是服务器返回的 JSON 数据体。

⑭ **`this.globalData.cityId = res.data.cityId;`**
- 把城市 ID 单独存一份，方便其他页面快速获取。

⑮ **`wx.removeStorageSync('token')`**
- 如果服务器说 token 无效（状态码不是 200），就删掉本地缓存的 token。
- 相当于门票过期了，从口袋里扔掉。

⑯ **`fail: () => { /* 不做处理 */ }`**
- 网络请求彻底失败时（连不上服务器、超时等），什么都不做。
- 注释里写了原因：不做清理，用户可手动重试。

## 4. utils/ —— 工具箱

### constants.js —— 看门大爷（环境判断）

```javascript
// 尝试加载生产配置
let prodConfig;
try {
  prodConfig = require('./config.prod.js');
} catch (e) {
  prodConfig = require('./config.default.js');
}

const PROD_API_HOST = prodConfig.PROD_API_HOST;

function getApiHost() {
  // 如果 config.prod.js 存在且配置了有效域名
  if (PROD_API_HOST && PROD_API_HOST !== '__PROD_API_HOST_NOT_CONFIGURED__') {
    return PROD_API_HOST;   // 走生产域名
  }

  // 没有生产配置时
  try {
    const info = wx.getAccountInfoSync();          // 获取小程序环境信息
    const env = info.miniProgram.envVersion;        // 'develop' 开发 | 'trial' 体验 | 'release' 正式
    if (env === 'release' || env === 'trial') {
      throw new Error(                              // 正式/体验环境没配域名 → 抛错阻止启动
        '[biz-reporting] 生产环境 API_HOST 未配置！\n' +
        '请复制 utils/config.default.js 为 config.prod.js，\n' +
        '并将其中的 PROD_API_HOST 替换为云托管域名。'
      );
    }
  } catch (e) {
    if (e.message && e.message.includes('PROD_API_HOST')) {
      throw e;                                      // 把错误往上抛，小程序启动失败
    }
  }
  return 'http://localhost:3000';                   // 开发环境 → 本地调试
}

const API_HOST = getApiHost();                      // 执行函数，得到最终 API 地址
const API_PREFIX = '/api';                          // 所有接口都挂在这个前缀下
const BASE_URL = `${API_HOST}${API_PREFIX}`;        // 拼成完整基础 URL

module.exports = { API_HOST, API_PREFIX, BASE_URL };
```

**大白话解读：**

这个文件的作用是**决定小程序该连哪个服务器**。

- `config.default.js` 是一个模板文件，里面是占位符 `__PROD_API_HOST_NOT_CONFIGURED__`。
- `config.prod.js` 是真正的生产配置文件，里面写了真实的服务器地址 `https://zy-data-d2g9g1ghr47ac6254.service.tcloudbase.com`。

**流程：**
1. 先试着加载 `config.prod.js`。如果不存在（开发环境），就加载 `config.default.js`。
2. 如果生产配置存在且有真实域名 → 所有环境（包括开发工具）都用这个地址。
3. 如果生产配置不存在：
   - 在开发者工具里（`develop` 环境）→ 用 `http://localhost:3000` 连本地后端。
   - 在体验版或正式版（`trial`/`release`）→ **直接报错不让启动**，提醒开发者必须先配好域名。这是一个安全机制，防止上线后请求跑错地方。

`module.exports = {...}` 是 Node.js/小程序把函数暴露出去的方式。其他文件 `require` 这个文件后，就能拿到 `BASE_URL` 等变量。

### request.js —— 快递员（网络请求）

```javascript
const { BASE_URL } = require('./constants');    // 拿 API 基础地址

function request(options) {                      // ①
  return new Promise((resolve, reject) => {      // ②
    const token = wx.getStorageSync('token');    // ③
    wx.request({                                  // ④
      url: `${BASE_URL}${options.url}`,           // ⑤
      timeout: 15000,                             // ⑥
      method: options.method || 'GET',             // ⑦
      data: options.data,                          // ⑧
      header: {
        'Authorization': token ? `Bearer ${token}` : '',  // ⑨
        'Content-Type': 'application/json',       // ⑩
      },
      success: (res) => {                         // ⑪
        if (res.statusCode === 401) {             // ⑫
          wx.removeStorageSync('token');          // ⑬
          wx.redirectTo({ url: '/pages/login/login' });  // ⑭
          reject({ code: 401, message: '登录已过期' });   // ⑮
          return;
        }
        if (res.statusCode >= 200 && res.statusCode < 300) {  // ⑯
          resolve(res.data);                      // ⑰
        } else {
          reject({                                // ⑱
            code: res.statusCode,
            message: (res.data && res.data.message) || '请求失败',
          });
        }
      },
      fail: (err) => {                            // ⑲
        reject({ code: -1, message: '网络错误', detail: err });
      },
    });
  });
}

module.exports = { request, BASE_URL };           // ⑳
```

**逐句翻译：**

① **`function request(options)`**
- 定义一个函数叫 `request`，`options` 是传入的参数对象。
- 调用时像这样：`request({ url: '/me', method: 'GET' })`。

② **`return new Promise((resolve, reject) => {...})`**
- Promise 是 JS 里处理异步操作的标准写法。
- `resolve` 表示操作成功，`reject` 表示操作失败。
- 调用 `request()` 后可以这样用：
  ```javascript
  request({url:'/me'}).then(data => { 成功 }).catch(err => { 失败 })
  ```

③ **`const token = wx.getStorageSync('token');`**
- 每次请求都从缓存里拿 token，保证请求带上身份标识。

④ **`wx.request({...})`**
- 微信小程序提供的 API，用来发起 HTTP 网络请求。
- 类比：`wx.request` 就像你打电话给服务器。

⑤ **`` url: `${BASE_URL}${options.url}` ``**
- 拼出完整 URL。比如 `BASE_URL` 是 `https://api.example.com/api`，`options.url` 是 `/me`，结果就是 `https://api.example.com/api/me`。

⑥ **`timeout: 15000`**
- 15 秒超时。超过 15 秒没响应就算失败。

⑦ **`method: options.method || 'GET'`**
- 请求方法。如果调用时传了 `method` 就用传的，否则默认用 `GET`。
- HTTP 请求方法：`GET`（获取数据）、`POST`（提交数据）、`PUT`（修改数据）、`DELETE`（删除数据）。

⑧ **`data: options.data`**
- 要发送给服务器的数据。比如登录时要传用户名密码。

⑨ **`'Authorization': token ? \`Bearer ${token}\` : ''`**
- 三目运算符：`条件 ? 成立时取值 : 不成立时取值`。
- 如果有 token，就在请求头里带上 `Bearer xxxxxx`。没有就不带。
- 
⑩ **`'Content-Type': 'application/json'`**
- 告诉服务器：我发的内容是 JSON 格式的。

⑪ **`success: (res) => {...}`**
- 请求成功的回调。注意这里的"成功"只代表**服务器有响应**（不管返回什么状态码）。

⑫ **`res.statusCode === 401`**
- 401 是 HTTP 状态码，表示"未授权"——token 过期了或被拒绝了。

⑬ **`wx.removeStorageSync('token')`**
- 删掉过期的 token。

⑭ **`wx.redirectTo({ url: '/pages/login/login' })`**
- 跳转到登录页，让用户重新登录。`redirectTo` 会替换当前页面（不能返回）。

⑮ **`reject({ code: 401, message: '登录已过期' })`**
- 告诉调用者请求失败，原因：登录过期。

⑯ **`res.statusCode >= 200 && res.statusCode < 300`**
- HTTP 状态码 2xx 都算成功（200=OK，201=创建成功，204=无内容）。

⑰ **`resolve(res.data)`**
- 告诉调用者请求成功，并返回服务器返回的数据。
- 注意这里**只返回 `res.data`**，而不是完整的响应。调用者拿到的就是数据本身，不用再解包。

⑱ **`reject({...})`**
- 其他状态码（400=参数错误、500=服务器错误等）都算失败，把状态码和错误信息返回给调用者。

⑲ **`fail: (err) => {...}`**
- 网络层面的失败（连不上服务器、DNS 解析失败等）。
- `reject` 返回错误码 `-1`（自定义，表示网络问题）。

⑳ **`module.exports = { request, BASE_URL }`**
- 把这个文件里的 `request` 函数和 `BASE_URL` 暴露出去，其他文件可以 `require` 使用。

### auth.js —— 保安（身份认证）

```javascript
const { BASE_URL } = require('./constants');

// ---------- 微信登录 ----------
function wechatLogin() {
  return new Promise((resolve, reject) => {
    wx.login({                           // ①
      success: (res) => {
        if (!res.code) {                 // ②
          reject({ message: '微信登录失败' });
          return;
        }
        wx.request({                     // ③
          url: `${BASE_URL}/auth/wechat/login`,
          method: 'POST',
          data: { code: res.code },      // ④
          header: { 'Content-Type': 'application/json' },
          success: (apiRes) => {
            if (apiRes.statusCode === 200) {
              const data = apiRes.data;
              wx.setStorageSync('token', data.token);     // ⑤
              wx.setStorageSync('userInfo', data.user);   // ⑥
              resolve(data);
            } else if (apiRes.statusCode === 404) {        // ⑦
              resolve({ needRegister: true, code: res.code });
            } else {
              reject({...});
            }
          },
          fail: (err) => { reject({...}); },
        });
      },
      fail: (err) => { reject({...}); },
    });
  });
}

// ---------- 微信注册 ----------
function wechatRegister(name, cityId) {
  return new Promise((resolve, reject) => {
    wx.login({
      success: (loginRes) => {
        wx.request({
          url: `${BASE_URL}/auth/wechat/register`,
          method: 'POST',
          data: { code: loginRes.code, name, cityId },
          success: (apiRes) => {
            if (apiRes.statusCode === 200 || apiRes.statusCode === 201) {
              wx.setStorageSync('token', apiRes.data.token);
              wx.setStorageSync('userInfo', apiRes.data.user);
              resolve(apiRes.data);
            } else { reject({...}); }
          },
          fail: (err) => { reject({...}); },
        });
      },
      fail: (err) => { reject({...}); },
    });
  });
}

module.exports = { wechatLogin, wechatRegister, getMe };
```

**大白话解读：**

① **`wx.login()`**
- 微信提供的 API，获取一个**临时 code**（可以理解为一次性门票）。
- 这个 code 有效时间很短（几分钟），需要马上发给后端换成真正的 token。

② **`if (!res.code)`**
- 如果 `wx.login` 成功了但没有返回 code，说明微信登录异常，拒绝。

③ **`wx.request({ url: '.../auth/wechat/login' })`**
- 把 code 发给后端的微信登录接口。后端会用 code 去微信服务器换用户的 `openid`（微信用户唯一 ID），然后生成 token 返回。

④ **`data: { code: res.code }`**
- 发送给服务器的数据：就是刚刚从 `wx.login` 拿到的 code。

⑤ **`wx.setStorageSync('token', data.token)`**
- 把服务器返回的 token 存到本地缓存。以后每次请求都带上它。

⑥ **`wx.setStorageSync('userInfo', data.user)`**
- 把用户信息（名字、角色、城市等）也存到本地。

⑦ **`res.statusCode === 404`**
- 如果服务器返回 404，说明这个微信用户还没注册过。登录函数会告诉调用者：`needRegister: true`（需要先注册）。

**整体流程：**
```
用户点"微信一键登录"
  → wx.login() 拿到临时 code
  → 把 code 发给后端 /auth/wechat/login
  → 后端查数据库：
      - 找到用户 → 返回 token（登录成功）
      - 没找到用户 → 返回 404（需要先注册）
  → 前端收到 404 → 显示注册表单让用户填姓名和城市
  → 用户填完点"注册并登录"
  → 再次 wx.login() 拿新 code + 姓名 + 城市 → 发往后端 /auth/wechat/register
  → 后端创建用户 → 返回 token
  → 前端存 token → 跳转到首页
```

```javascript
    wx.request({
      url: `${BASE_URL}/cities`,
      success: (res) => { if (res.statusCode === 200) { this.setData({ cityList: res.data }); } },
      fail: () => { this.setData({ cityList: [] }); },
    });
  },

  handleRegister() {                        // ⑬
    const { name, selectedCity } = this.data;
    if (!name.trim()) { this.setData({ errorMsg: '请输入姓名' }); return; }
    if (!selectedCity) { this.setData({ errorMsg: '请选择城市' }); return; }

    this.setData({ registerLoading: true, errorMsg: '' });
    wechatRegister(name.trim(), selectedCity.id)
      .then(() => { wx.redirectTo({ url: '/pages/index/index' }); })
      .catch((err) => { this.setData({ registerLoading: false, errorMsg: err.message || '注册失败' }); });
  },

    this.setData({ showRegister: false, errorMsg: '', name: '', selectedCity: null });
```

**逐句翻译：**

① **`Page({...})`**
- 微信小程序提供的函数，用来注册一个页面。里面写的对象就是这个页面的所有行为和数据。

② **`data: {...}`**
- 页面的数据。这些数据可以在 WXML 模板里用 `{{变量名}}` 显示。
- 要修改数据必须用 `this.setData(...)`，不能直接赋值。

③ **`onLoad()`**
- 页面生命周期函数。**页面加载时自动执行一次**。
- 这里做的是：提前加载城市列表，等用户注册时就能直接选。

④ **`onAgreePrivacyChange()`**
- 点击隐私协议复选框时触发。
- `!this.data.agreePrivacy` 表示取反：原来是 true 变成 false，原来是 false 变成 true。

⑤ **`handleLogin()`**
- 点击"微信一键登录"按钮时触发。

⑥ **`if (!this.data.agreePrivacy)`**
- 如果没有勾选"已阅读并同意协议"，弹提示不让登录。

⑦ **`this.setData({ loading: true, errorMsg: '' })`**
- `setData` 是 WXML 数据绑定的关键方法。
- `loading: true` 让按钮显示"登录中..."并进入加载状态。
- `errorMsg: ''` 清除之前显示的错误提示。

⑧ **`wechatLogin()`**
- 调用 `utils/auth.js` 里的登录函数（前面已经详细讲过）。

⑨ **`if (res.needRegister)`**
- 如果登录函数返回 `needRegister: true`，说明用户还没注册过，显示注册表单。

⑩ **`wx.redirectTo({ url: '/pages/index/index' })`**
- 跳转到首页。`redirectTo` 会关闭当前页面（不能通过返回键回到登录页）。

⑪ **`.catch((err) => {...})`**
- Promise 的失败处理。登录失败时显示错误消息。

⑫ **`loadCityList()`**
- 加载城市列表。调用后端的 `/cities` 接口（公开接口，不需要登录）。
- 城市列表会在注册时让用户选择所在城市。

⑬ **`handleRegister()`**
- 点击"注册并登录"时触发。
- 先校验：姓名不能为空、城市必须选。
- 校验通过后调用 `wechatRegister()` 完成注册和登录。

⑭ **`backToLogin()`**
- 返回登录界面。重置所有注册相关数据和状态。

```javascript
const { request, BASE_URL } = require('../../utils/request');

Page({
  data: {
    year: new Date().getFullYear(),     // 当前年份（如 2026）
    isLoggedIn: false,                   // 是否已登录

    summary: { completionTotal: 0, acceptanceTotal: 0, costTotal: 0, grossProfit: 0 },  // 汇总

    enableMaintenance: false,            // 是否启用维保功能
  },

  onLoad() {
    this.checkAuthAndLoad();    // 页面加载时检查登录并加载数据
  },

  onShow() {
    this.checkAuthAndLoad();    // 页面每次显示时重新检查（比如从其他页返回）
    this.refreshUnreadCount();  // 刷新未读消息数
  },

  checkAuthAndLoad() {
    const token = wx.getStorageSync('token');
    if (!token) {
      this.setData({ isLoggedIn: false });  // 没 token → 显示未登录界面
      return;
    }
    // 用 token 调 /me 接口验证
    wx.request({
      url: `${BASE_URL}/me`,
      header: { Authorization: `Bearer ${token}` },
      success: (res) => {
        if (res.statusCode === 200) {
          this.setData({ isLoggedIn: true, userInfo: res.data });
          this.loadPackage(this.data.year);    // 加载年度报表包
          this.loadCityConfig();               // 加载城市配置
          this.refreshUnreadCount();           // 刷新未读数
        } else {
          this.clearTokenAndShowGuest();       // token 无效 → 清掉并显示游客界面
        }
      },
      fail: () => {
        // 网络错误：假装已登录，只显示空数据
        this.setData({ isLoggedIn: true, pkgStatus: 'empty' });
        this.refreshUnreadCount();
      },
    });
  },

  refreshUnreadCount() {
    // 调用 /messages/unread-count 接口获取未读消息数
    wx.request({
      url: `${BASE_URL}/messages/unread-count`,
      header: { Authorization: `Bearer ${token}` },
      success: (res) => {
        if (res.statusCode === 200) {
          this.setData({ unreadCount: Number(res.data.unreadCount || 0) });
        }
      },
    });
  },

  // 加载年度报表包数据
  loadPackage(year) {
    request({ url: `/city/packages/current?year=${year}` })
      .then((data) => {
        // 构造 12 个月的数据结构
        const months = [];
        for (let m = 1; m <= 12; m++) {
          const monthData = data.months ? data.months.find(mth => mth.monthNo === m) : null;
          months.push({ monthNo: m, submitted: monthData ? monthData.submitted : false });
        }
        // 计算统计
        const submittedCount = months.filter(m => m.submitted).length;
        this.setData({
          pkgStatus: 'loaded',
          packageData: data,
          months,
          stats: { submitted: submittedCount, pending: 12 - submittedCount - overdueCount, ... },
        });
      })
      .catch(() => { this.setData({ pkgStatus: 'empty' }); });
  },

  // 点击月份
  onMonthTap(e) {
    if (!this.data.isLoggedIn) {
      wx.showModal({ title: '请先登录', content: '填报数据需要微信登录验证身份。', ... });
      return;
    }
    const monthNo = Number(e.currentTarget.dataset.month);
    wx.navigateTo({
      url: `/pages/package-month/package-month?packageId=${...}&monthNo=${monthNo}&...`,
    });
  },

  // 跳转消息中心
  onMessagesTap() {
    wx.navigateTo({ url: '/pages/messages/messages' });
  },

  // 跳转登录页
  onLoginTap() {
    wx.navigateTo({ url: '/pages/login/login' });
  },
});
```

**核心逻辑流程：**

```
用户打开小程序
  → app.js 的 onLaunch() 检查 token
  → 首页 onLoad() 调用 checkAuthAndLoad()
  
情况 1：没有 token
  → 显示"未登录"界面（含功能介绍、12 个月网格、微信登录按钮）

情况 2：有 token 且有效
  → 加载年度报表包、城市配置、未读消息数
  → 显示 12 个月的实际提交状态、统计数字、汇总数据

情况 3：有 token 但已过期
  → 删除 token → 显示游客界面

用户点击某个月份
  → 跳转到 package-month 页面
  → URL 参数携带：packageId、monthNo、enableMaintenance、pkgStatus

用户点击"消息中心"
  → 跳转到 messages 页面
```

**wx.navigateTo 和 wx.redirectTo 的区别：**
- `navigateTo`：打开新页面，保留当前页（可以返回）。
- `redirectTo`：关闭当前页，打开新页面（不能返回）。

```javascript
  const n = Number(value);
  return Number.isFinite(n) ? n : 0;  // 如果是有效数字就返回，否则返回 0
}
```
这个函数确保输入框里即使输入了非法字符（比如字母），最后存到数据里的也是合法数字 0。

## 8. pages/messages —— 消息中心

### 逻辑（messages.js）

```javascript
const { BASE_URL } = require('../../utils/constants');

Page({
  data: {
    loading: true,
    status: 'loading',     // loading | ready | empty | guest | error
    messages: [],
    unreadCount: 0,
    errorMessage: '',
    isLoggedIn: false,
  },

  onLoad() { this.loadMessages(); },
  onShow() { this.loadMessages(); },  // 每次显示都重新加载

  loadMessages() {
    // 1. 检查登录态
    const token = wx.getStorageSync('token');
    if (!token) {
      this.setData({ status: 'guest' });  // 未登录 → 显示"请先登录"
      return;
    }
    
    // 2. 请求消息列表
    wx.request({
      url: BASE_URL + '/messages',
      method: 'GET',
      header: { Authorization: 'Bearer ' + token },
      success: (res) => {
        if (res.statusCode === 200) {
          const msgList = (res.data.messages || []).map((m) => {
            // 格式化时间：把 "2026-06-29T10:30:00" 变成 "2026-06-29 10:30"
            let time = m.createdAt || '';
            if (time) time = time.slice(0, 16).replace('T', ' ');
            return { id, title, summary, isRead, createdAt: time, payloadJson };
          });
          this.setData({
            messages: msgList,
            status: msgList.length ? 'ready' : 'empty',
            loading: false,
          });
        }
      },
    });
  },

  // 点击某条消息 → 标记已读 → 重新加载
  onMsgTap(e) {
    const id = e.currentTarget.dataset.id;
    this.markMessageRead(id).finally(() => { this.loadMessages(); });
  },

  markMessageRead(messageId) {
    return new Promise((resolve) => {
      wx.request({
        url: BASE_URL + '/messages/' + messageId + '/read',
        method: 'POST',
        header: { Authorization: 'Bearer ' + token },
        complete: () => resolve(),
      });
    });
  },
});
```

**核心逻辑：**

```
进入消息中心
  → 检查是否有 token
  → 有：调 /messages 接口获取消息列表
  → 无：显示"未登录"提示

点击消息
  → 调用 /messages/{id}/read 标记已读
  → 重新加载消息列表（未读数会变化）

5 种页面状态：
  loading  → 加载中
  ready    → 有消息
  empty    → 暂无消息
  guest    → 未登录
  error    → 加载失败
```

### 模板关键点（messages.wxml）

```html
<view class="panel" wx:else>
  <view class="msg-list">
    <view
      class="msg-item {{msg.isRead ? '' : 'unread'}}"  <!-- 未读消息有特殊样式 -->
      wx:for="{{messages}}" wx:key="id"
      data-id="{{msg.id}}" bindtap="onMsgTap"
    >
      <view class="msg-left">
        <view class="msg-dot" wx:if="{{!msg.isRead}}"></view>  <!-- 未读小蓝点 -->
      </view>
      <view class="msg-body">
        <view class="msg-head">
          <text class="msg-title">{{msg.title}}</text>
          <text class="msg-tag" wx:if="{{!msg.isRead}}">未读</text>
        </view>
        <text class="msg-summary">{{msg.summary}}</text>
        <text class="msg-time">{{msg.createdAt}}</text>
      </view>
    </view>
  </view>
</view>
```

**逐句解读：**
1. `class="msg-item {{msg.isRead ? '' : 'unread'}}"`：三目运算符控制 CSS class。已读消息不加额外 class，未读消息加 `unread` class（有蓝色左边框）。
2. `data-id="{{msg.id}}"`：把消息 ID 存在 DOM 上。点击时 `e.currentTarget.dataset.id` 获取。
3. `wx:if="{{!msg.isRead}}"`：未读消息才显示小蓝点。
4. `msg-title`：消息标题。`msg-summary`：消息摘要。`msg.createdAt`：创建时间。

## 总结：完整用户流程

```
1. 用户打开小程序
   ↓
2. app.js onLaunch()
   → 检查本地是否有 token
   → 有 token 则验证是否有效（调 /me）
   ↓
3. 首页 index 显示
   → 无 token 或 token 无效 → 显示"未登录"界面
   → 有 token → 加载年度报表包、城市配置、未读消息数
   ↓
4. 用户点击"微信一键登录"
   → wx.login() 获取临时 code
   → 后端用 code 换 openid → 查用户表
   → 已注册 → 返回 token → 跳首页
   → 未注册 → 显示注册表单
   ↓
5. 注册：填姓名 + 选城市 → 注册并登录 → 跳首页
   ↓
6. 首页（已登录）
   → 看到 12 个月网格（已提交/待填报）
   → 看到统计数据、汇总金额
   → 点消息中心 → 查看未读消息
   ↓
7. 点击某个月份
   → 进入月度填报页
   → 输入合同完工/审定金额
   → 输入 7 类费用金额
   → 保存草稿 / 提交预览 / 确认提交
   ↓
8. 提交后：该月份变为只读状态
```
