# 经营数据中台地市端使用手册

更新时间：2026-07-29

## 登录与账号

1. 账号由 `root_admin` 预建并绑定地市，系统不提供公开注册。
2. 地市用户使用地市密码登录，或使用一次性微信邀请完成绑定后登录。
3. 临时密码首次登录只能进入用户设置修改密码；改密成功后需重新登录。
4. 账号、角色或地市有误时联系 `root_admin`，不要尝试选择其他地市。

## 主要页面

- 本地市总览：查看合同月度进度、订单、实际成本、利润和数据更新时间。
- 本地市数据：查看并维护合同月度完工、审定和开票进度。
- 本地合同：只读查看当前地市已分配合同和生效管理费率。
- 本地市成本：导入或在线维护成本事实，支持筛选、追溯和冲销。
- 本地市订单：导入或在线维护订单行，取消和负数作为合法冲销处理。
- 数据接入与历史：查看导入批次、错误行、来源文件和变更记录。
- 用户设置：验证原密码后修改当前账号密码。

## 数据维护规则

- Excel 导入先完成字段识别、地市和合同匹配；存在阻塞错误时整批不写入。
- 校验通过后数据直接成为当前有效事实，不再执行正式提交、月份锁定、解锁或退回草稿流程。
- 在线编辑保存后立即更新，并记录修改人、时间、原因、前后值和版本。
- 成本与成本预算分开；订单按每个来源行的含税金额汇总。
- 地市范围来自登录账号，不能通过 URL、筛选参数或导出参数切换到其他地市。

## 导出与密码

- “导出本页”继承当前年度、月份、合同、状态、分类和关键词筛选，分页列表导出全部筛选结果。
- 修改密码必须输入正确原密码，新密码为 8–128 位且不能与旧密码相同。
- 改密后旧密码和旧 JWT 立即失效，页面自动返回登录页。

当前部署状态以 `specs/rbac-auth-export-settings/validation-report.md` 为准；本手册不表示生产部署已完成。
