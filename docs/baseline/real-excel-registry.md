## 5. 受控约定

1. 真实 Excel 仅用于本地开发库与受控验收环境的模板冻结、算法验证与受控测试。
2. 自动化测试夹具一律使用 `golden-samples.json` 中的脱敏虚构值，不使用真实文件。
3. 真实文件哈希用于 M4 的「文件哈希 + 最大下单时间」重复文件控制逻辑的受控验证。
4. 任何情况下不得把真实文件或其内容提交 Git、写入公开测试包或在测试截图/日志中暴露完整敏感字段。
